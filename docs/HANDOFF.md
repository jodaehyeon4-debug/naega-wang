## 2. 저장소 구조와 빌드·배포 방법

```
naega-wang/
├─ index.html          ← 배포되는 완성본(빌드 결과 dist/index.html 복사본)
├─ README.md
├─ src/                ← 소스(모듈) — 여기서 고치고 빌드
│  ├─ build.py         ← 모듈을 이어 붙여 king.html / test.html / game.js / dist/index.html 생성
│  ├─ v1_css.css, v2_add.css
│  ├─ v2_*.js          ← 기능별 모듈(아래 순서로 하나의 즉시 실행 함수 안에 합쳐짐)
│  └─ tools/           ← 시험 스크립트(sim2.py, evcheck.py 등). 안의 경로는 옛 작업 폴더 기준이라 실행 전 BASE 경로만 고치면 됨
└─ docs/
   ├─ HANDOFF.md       ← 이 문서
   ├─ guides/          ← 학생용 설명서·교사용 가이드·게임하는 법(HWPX) + 만든 스크립트(make*.py, python-hwpx 사용)
   └─ relics/          ← 유물 사진 목록(xlsx), 상상도 3장(유기·서기·국사) + draw.py
```

### 빌드 순서 (build.py 안)
`v2_data → main1 → pol → ev → ev2 → variety → flow → kings → sillok → scen5 → mapdata → map → mapworld_data → mapworld → real → ifs → late → feat → alt → legend → hell → more → treasure → era → tier → reveal → export → render`

- 모든 모듈은 하나의 IIFE 안에 이어 붙여져 **같은 스코프**를 공유해요(`const`는 순서 주의: 앞 모듈의 `const`를 뒤에서만 쓸 수 있음, `function` 선언은 어디서든 가능).
- `test.html`에는 `window.__K`(시험용 훅)가 들어가고, `window.__FAST = true`면 화면 그리기를 건너뛰어 시뮬레이션이 빨라요.

### 배포 절차
```bash
cd src && python3 build.py && node --check game.js
cp dist/index.html ../index.html
cd .. && git add -A && git commit -m "…" && git push origin main && git push origin main:gh-pages
```

## 3. 게임 시스템 전체

### 3-1. 기본 흐름
- 시작: 왕 이름 · 나라(시나리오) · 다스림 원칙 3가지(목표 능력치, 시작 가산) 고르기.
- **능력치 6개**: 왕권(王)·화합(和)·민심(民)·재정(財)·국방(兵)·문화(文). 하나라도 0이 되면 즉시 붕괴(역사 속 실제 붕괴 사례와 팁이 나옴).
- 한 시기 = ① 사건 선택 → ② 나라 살림(세금 방식, 국력 안 듦) → ③ 정책 카드(국정 힘 2개 안팎, 1시기는 3개, 남은 힘 최대 2개 이월) → ④ 실록(결과) 읽기.
- **세월의 흐름**: 매 시기 국방 −3, 민심 −2, 왕권 −1, 세금 +4 + 수입. 조건에 따라 추가 증감.
- 10시기 뒤 결과: 나라의 운명, 시호(묘호), 닮은 왕 공개 연출, 7등급 티어, 실록 PDF·결과 카드 PNG 저장.

### 3-2. 선택지 다양성
- 사건 선택지 일부만 보여 주고, 지난 판에 안 고른 선택지를 우대(`SEEN`, '안 가 본 길' 표시).
- 같은 선택 반복 시 효과 감소. '왕이 먼저 사치 줄이기' 같은 늘 정답인 선택은 상황에 따라 결과가 달라지게 수정.
- **모험(gamble)** 선택지: 성공 확률 표시, 성공·실패 결과 모두 표시.

### 3-3. 지도
- 한국사: Natural Earth 1:10m 해안선, 나라별 영역(경계는 부드러운 곡선 공유), 침입·원정 화살표, 시기마다 땅 변화.
- 세계사: 몽골(동아시아~동유럽), 아메리카 원주민(미국 본토), 프랑스 혁명·흑사병 잉글랜드(유럽), 촉한(중국). 지도마다 투영을 바꾸는 `geoUse()` 사용.
- 정복 정책은 **"우리 힘 n / 이기려면 m"**(우리 힘 = 국방 + 성 쌓기 8 + 동맹 10 + 화랑도 5 + 의병 6 + 왕권×0.1).

### 3-4. 시대에 맞는 정책 이름 (v2_era.js)
- 같은 정책이라도 나라·시대별로 이름·설명·실록 문장을 바꿔 보여 줌(효과 숫자는 같음).
  - 예: 귀족 회의 → 고구려 제가 회의 / 백제 정사암 회의 / 신라 화백 회의 / 고려 도병마사 / 조선 비변사 / 대한 제국 만민 공동회.
  - 대한 제국의 처음부터 있던 제도는 홍범 14조, 13도, 신분제 폐지, 국문 등 갑오개혁 모습으로.
- 시대에 맞지 않는 정책은 숨김(삼국의 노비안검법, 세종 때 균역법·대동법·탕평책 등).

### 3-5. 핵심 정책 (형성평가용, 화면 표시 없음)
- 교과서에서 그 시대 발전의 열쇠로 배우는 정책은 **좋은 효과 ×1.4, 나쁜 효과 ×0.6**(숨은 가산).
  - 삼국: 율령, 관등, 불교 + 고구려 태학 / 백제 바다 교역 / 신라 화랑도
  - 고려: 혼인·사성, 기인, 과거제, 노비안검법, 12목, 국자감
  - 세종: 집현전, 훈민정음, 과학 기구, 공법
  - 조선 중후기: 임진왜란 훈련도감·판옥선과 거북선 / 병자호란·경신 대기근 대동법·환곡·진휼청 / 영조 탕평책·균역법
  - 대한 제국: 광무 양전·지계, 신식 군대, 신문, 국채 보상, 민족 학교, 의병 / (국권 피탈 뒤) 임시 정부, 광복군, 독립군 기지, 조선어 학회, 민족 교육, 물산 장려
- **원칙: 고유 정책·일반 정책이 핵심 정책보다 효율이 높아서는 안 됨**(`coreaudit.py`로 확인).

### 3-6. 나라 고유 정책 ('숨은 역사' 표시)
조명받지 못한 실제 이야기나 역사적 상상. 효율은 핵심 정책보다 낮게.
- 고구려: 온달, 광개토대왕 수군, 담징 / 백제: 칠지도, 가야와 철 동맹 / 신라: 우륵, 6두품 등용(상상) / 고려: 대광현, 서경, 시무 28조 / 세종: 장영실, 향약집성방, 농사직설 / 영조: 신문고, 북학(상상) / 임진왜란: 훈련도감, 판옥선·거북선, 의병장 / 병자호란: 강화도, 밀정(상상), 소현 세자 서양 학문(상상) / 경신 대기근: 신간구황촬요, 활인서
- 대한 제국 고유: 민족 학교, 의병 돕기, 독립문, 대한천일은행, 칙령 제41호(독도), 간도 관리사(모험) / 국권 피탈 뒤: 어린이날(방정환), 한인 애국단(모험)

### 3-7. 만약에? (역사적 상상 모험, v2_ifs.js)
- 확률 등급: **초모험 20%대(국력 4개, 조건마다 +1%) · 모험 30~35% · 쉬운 모험 55%까지**. '조금만 더'에서는 일반 +10%, 초모험 +8%.
- 고구려 삼국 통일·요서·중원(초모험 2→20%), 백제 왜 진출·산둥·바닷길 왕국·왜 정벌(초모험), 신라 삼국 통일·나당 전쟁·만주(초모험), 고려 벽란도 허브·서희 담판·요동 되찾기(초모험), 조선 대마도 편입·만주(초모험).

### 3-8. 역사 속 왕의 위업 (v2_feat.js, v2_alt.js)
- 나라마다 3개. 정책 화면 위 '위업 0/3' 표시, 달성하면 실록에 '위업 달성!'과 실제 걸린 기간 표시. 위업 하나에 왕력 +3, 모두 +3 추가.
- 업적이 너무 쉽게 되지 않게 **단계별**로: 세종 4군(1차 정벌 64 → 4군 설치 68), 6진(김종서 62 → 사민 정책 → 6진 완성 68), 신라 가야(금관가야 평화 → 대가야 60).
- 위업 목록 예: 세종(훈민정음·4군 6진·과학과 공법), 영조(탕평비·균역법·청계천 준천), 임진왜란(수군·훈련도감·7년 전쟁 승리), 대한 제국(광무개혁·국민 애국 운동·나라 지키기/되찾기), 세계사(칭기즈 칸 천호제·역참·예케 자사크 등).

### 3-9. 다른 역사 결말 (정책 시너지)
핵심 정책 대신 숨은 정책을 조합하면 실제보다 나은 결말(왕력 +5, '다른 역사' 표시). 우연히는 0~7%, 노리면 10~50%.
- 붓으로 천 년을 이은 고구려(문민 중시), 바다로 나간 고구려, 철의 동맹으로 한성을 지킨 백제, 골품제를 넘어선 신라, 가야와 하나 된 신라, 발해를 품은 고려, 호족과 함께 다스린 고려, 과학 혁명의 조선, 북학으로 부강해진 조선, 백성의 목소리를 듣는 조선, 전쟁 뒤 더 강해진 조선, 실리 외교로 전쟁을 피한 조선, 새 학문을 받아들인 조선, 굶는 사람 없는 조선, 스스로 근대화에 성공한 대한 제국.

### 3-10. 전설의 히든 정책 (v2_legend.js)
정해진 정책 3~4개 + 수치 조건이 맞을 때만 몰래 나타나는 카드(100판 중 1~6판). 나라당 1개.
- 삼족오 철갑 기병대 / 동아시아 최고의 금동 공방 / 화랑 천 명의 대연합 / 아라비아 나침반 함대 / 하늘을 나는 비거 / 영국 사신과 증기 기관(한양 지하철) / 물속을 다니는 거북선 / 강화도 비밀 굴과 홍이포 / 백 년 먼저 온 고구마와 감자 / 대한 제국 비행선 함대

### 3-11. 조건 알림
- 조건이 걸린 정책(무역=국방 40, 철도=국방 30, 화폐=민심 40)을 펼친 뒤, 수치가 기준+10 아래로 내려오면 **화면 오른쪽 아래에 고정 알림**('주의! … 효과가 약해져요'). 기준 아래면 실제로 매 시기 재정 손해.

### 3-12. 화합 정책
- 큰 회의(나라별 이름 다름, 화합 +8, 화합 35 미만이면 +13, 3시기마다), 사냥 대회(모험, 60~80%, 성공 화합 +10).

### 3-13. 티어(1등이 누구야?) · 명예의 전당 (v2_tier.js)
- 왕력 점수 = 능력치 평균 + 업적 + 고르게 키운 정도 + 다짐 지키기 + 넓힌 땅 + 만약에 성공 + 위업 + 다른 역사 + 걸작 + 난이도(★) − 폭정.
- S 천하제일 대왕(82+) · A 역사에 빛나는 성군(72+) · B 이름을 떨친 군주(63+) · C 나라를 지켜 낸 임금(54+) · D 고생 많았던 임금(45+) · E 아슬아슬 버틴 임금(30+) · F 무너진 나라의 왕.
- 명예의 전당은 **기기별 저장**(localStorage `king-hof-v1`). 같은 기기 친구끼리 비교.

### 3-14. 지옥급(★10) 시나리오 (v2_hell.js)
- 나라 카드에 빨간 별 10개 + 경고문. 실제 멸망 루트를 그대로 따라감. 무작위 플레이 93% 붕괴(대부분 1~2시기).
- **백제 656년(의자왕)**: 성충의 글 → 나당 연합군(기벌포·탄현) → 황산벌 계백 → 사비성. 성충 석방·길목 차단·왜와 동맹이면 생존.
- **촉한 221년(유비)**: 관우의 죽음(복수냐 화친이냐) → 이릉(숲속 진영=화공) → 백제성 탁고 → 칠종칠금 → 가정(마속) → 오장원 → 263년 음평 샛길.

### 3-15. 조금만 더 (11~20시기, v2_more.js)
- 10시기를 무사히 마치면 결과 화면에 버튼 → 다음 왕 이름 짓고 30년 더. 한국사 나라만(세계사·국권 피탈한 대한 제국 제외).
- 즉위 축하 전 능력치 +3, 국정 힘 +1, 만약에 확률 상승, '오래된 나라의 피로'(국방·민심·화합 −1/시기).
- 새 사건: 즉위식(약점 바로잡기/다른 길/신비한 의식), 선왕의 빈자리, 옛 신하, 도깨비 방망이, 바다의 용, 미래에서 온 책, 서역 상인, 비거, 왕자의 다툼, 지진, 큰 장터, 꼬리별, 두 왕의 역사책.
- 새 정책: 선왕의 실수 바로잡기, 나라의 걸작 짓기, (다른 길 선택 시) 바다 끝 탐험대·온 백성 대표 회의.
- 티어 = (선왕 점수 + 지금 점수)/2 − 2.

### 3-16. 걸작과 보물 상자 (v2_treasure.js)
- 정책 '나라의 걸작 만들기'(국력 2, 2시기마다) → 실록에 보물 상자가 열리며 실제 문화유산 1점 완성.
- 등급: 보통(문화 +8) · 희귀(+12) · 전설(+18, 민심·화합 +4). 걸작마다 매 시기 문화 +1(최대 3). 왕력 점수 가산.
- 결과 화면 '보물 창고': 모은 것은 등급 색, 못 모은 것은 '?' 카드(종류만 보임).
- 걸작 70점(한국사 50, 세계사 20). 목록은 `docs/relics/왕BTI_유물_사진_목록.xlsx`.
