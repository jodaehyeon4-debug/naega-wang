# 왕BTI (내가 왕이라면, 나는 어떤 왕일까?)

- 우리 역사 8개 · 세계사 4개 나라 (★★★★★ 4개 포함)
- 학생 이름과 기록은 각 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
- 파일 하나(index.html)로 동작합니다.
