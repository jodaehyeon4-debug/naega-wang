# 왕BTI (내가 왕이라면, 나는 어떤 왕일까?)

초등 5학년 역사 수업용 의사결정 게임입니다. 10시기 동안 나라를 다스리고, 나라의 운명과 닮은 왕, 과장된 실록을 받아 봅니다.

- 우리 역사 11개 · 상상 4개 · 세계사 5개 나라 (지옥급 ★10 2개 포함)
- 학생 이름과 기록은 각 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
- 파일 하나(index.html)로 동작합니다.

## 지도 자료
해안선: Natural Earth (공공 영역), world-atlas 패키지. 옛 나라의 경계는 교과서 지도를 바탕으로 한 대략적인 모습입니다.
